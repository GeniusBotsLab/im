# Security Policy

## Publication boundary

This is a public professional-profile repository. Do not add or report publicly:

- passwords, API keys, access tokens, private keys or certificates;
- `.env` files, production configuration or deployment access;
- customer, user or client data;
- internal infrastructure, database dumps, backups, logs or unpublished product materials;
- any materials belonging to the NeuroMedia core project or application.

Only standalone products explicitly approved for public release may be published in their own repositories.

## Reporting an issue

Do not disclose a security issue through a public Issue. Use the contact method documented in the affected public product repository and share only the minimum safe information needed for review.
