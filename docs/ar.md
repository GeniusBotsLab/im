# الملف المهني

**وكلاء ذكاء اصطناعي مستقلون · تنسيق متعدد الوكلاء · LLMOps · AgentOps · توجيه النماذج · تحسين تكلفة الرموز · نماذج LLM محلية · أتمتة 24/7**

أصمم وأطلق أنظمة وكلاء ذكاء اصطناعي مستقلة تحوّل سير العمل المعقد إلى خطوط أتمتة تعمل 24/7، قابلة للتحكم ومحسّنة من حيث التكلفة.

مهندس أنظمة ذكاء اصطناعي ومتخصص أتمتة رقمية بخبرة إنتاجية تزيد على 10 سنوات. أركز على الوكلاء المستقلين وأسراب الوكلاء والتنسيق متعدد الوكلاء والتوجيه بين نماذج LLM والتشغيل المحلي للنماذج مفتوحة المصدر وتحسين تكلفة الرموز.

أبني أنظمة إنتاج قابلة للتكرار، لا نصوصاً لمرة واحدة. يجمع الوكلاء البيانات ويحللونها، ويكتبون الكود وينفذونه، ويتعاملون مع API والمتصفحات والمستندات وTelegram وقواعد البيانات والخوادم، ثم يسلّمون النتائج بالشكل المطلوب.

## التخصص الأساسي

تصميم أنظمة وكلاء لمهام الأعمال والتقنية المحددة، من المعمارية وتوزيع الأدوار إلى الإطلاق والتصحيح والمراقبة وتحسين كلفة التنفيذ. تقسم تدفقات العمل متعددة الوكلاء المهام بين researcher وparser وanalyst وcoder وvalidator وreviewer وdispatcher وexecutor وreporter، ولكل وكيل سياقه وأدواته ونموذجه وقواعده.

أحسن تكلفة الرموز عبر توجيه النماذج وضغط المطالبات والتخزين المؤقت وتقليل السياق والمخرجات المهيكلة وLLM المحلية للمهام عالية الحجم وخطوط العمل الهجينة السحابية والمحلية. تذهب المهام البسيطة إلى نماذج اقتصادية، ومهام الاستدلال المعقدة إلى نماذج أقوى.

أشغّل Llama وMistral وQwen وغيرها من النماذج مفتوحة المصدر على بنية تحتية مملوكة للحفاظ على البيانات محلياً وتقليل الاعتماد على واجهات API الخارجية وضبط التكلفة.

## AgentOps / LLMOps

تشغيل إنتاجي يشمل تنفيذ 24/7 على خوادم مخصصة، وإعادة تشغيل تلقائية، ومنطق retry/fallback، وطوابير مهام، وسجلات للقرارات والأفعال، ومراقبة الحالة، والتحكم في استخدام الرموز، وhuman-in-the-loop للإجراءات الحساسة، والتحقق من النتائج، وتشغيل قابل للتكرار.

## القدرات والخبرة والتقنيات

جمع ومعالجة البيانات من المواقع وTelegram وAPI والمستندات والجداول والبريد الإلكتروني؛ البحث على الويب ومراقبة المصادر واستخراج الكيانات والتصنيف والمقارنة وإعداد التقارير؛ أتمتة الكود؛ التكامل مع المتصفحات وWebSocket وCRM وTelegram Bot API والملفات وقواعد البيانات والخدمات الخلفية؛ قرارات تعتمد على القواعد أو LLM أو منطق هجين؛ OSINT والمراقبة المعلوماتية.

يشمل العمل المنفذ وكلاء بيانات مستقلين وتدفقات عمل متعددة الوكلاء للبحث والكود والمحتوى والمراقبة والعمليات، وأتمتة Telegram، وأنظمة متعددة القنوات لـ Telegram وWhatsApp وFacebook وInstagram وTikTok وYouTube وX، وتدفقات محتوى LLM، وخطوط فيديو قصير، وبنية أتمتة بريد حتى 500 رسالة في الدقيقة، وشبكات بروكسي وطوابير وتكاملات API وخوادم ومحاكيات وبيئات VM.
