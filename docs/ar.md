# GeniusBotsLab — أنظمة الوكلاء وأتمتة الذكاء الاصطناعي الموثوقة

**مهندس أتمتة ذكاء اصطناعي لعمليات أعمال منضبطة وقابلة للقياس.**

أصمم أنظمة ذكاء اصطناعي يبحث فيها وكلاء متخصصون ويخططون وينفذون ويراجعون ويتحققون ويقدمون التقارير عبر تسليمات واضحة، وصلاحيات، وميزانيات، وسجلات، وموافقة بشرية للإجراءات المهمة.

## القدرات

- **تنسيق متعدد الوكلاء** — أدوار الباحث والمحلل والمخطط والمنفذ والمراجع والمدقق وإعداد التقارير، مع مسؤوليات محددة.
- **سير عمل طويل الأمد** — حالة، وطوابير، وجداول، ونقاط تحقق، وإعادات محاولة، ومهل زمنية، وتنبيهات، وسجلات تدقيق، وبوابات موافقة.
- **تسليم البرمجيات بمساعدة الذكاء الاصطناعي** — يساعد Claude وClaude Code وChatGPT في البحث والتنفيذ والمراجعة وتصميم الاختبارات والتوثيق؛ ويحتفظ البشر بمسؤولية المعمارية والأمن والتحقق والإصدارات والقرارات.
- **سير عمل اجتماعي وإعلامي مُصرّح به** — نشر مُعتمد، وإدارة التعليقات والرد عليها، وتخطيط المحتوى، وخطوط إنتاج الصور/الفيديو/الصوت، والتقارير والعمليات الداخلية.

## الممارسة الهندسية

```text
تدقيق العملية → مقاييس التجربة الأولية → الأدوار والوصول → البناء → الاختبارات وQA → إطلاق منضبط → مراقبة التكلفة والجودة والأخطاء → التحسين
```

تكون اختبارات الوحدة والتكامل والاختبارات الشاملة من البداية إلى النهاية إلزامية حيثما تنطبق، وتشغّل CI الفحوصات الآلية المتفق عليها. تُتحقق المدخلات والمخرجات المنظمة؛ وتُحال النتائج الملتبسة أو عالية الأثر إلى مراجعة بشرية.

### النماذج وRAG والموثوقية

- أوجّه النماذج وفق تعقيد المهمة ومتطلبات الجودة والتكلفة.
- أضبط السياق، وأخزن النتائج القابلة لإعادة الاستخدام مؤقتًا، وأضع ميزانيات للرموز والإجراءات.
- أستخدم RAG وسير العمل ذي الحالة عندما يكون الاسترجاع المستند إلى المصادر مناسبًا.
- أشغّل الأنظمة مع قابلية الرصد، والصلاحيات، وحالة التسليم، ومسارات إعادة المحاولة/البدائل، ومعالجة موثقة للإخفاقات.

## التقنيات

**الذكاء الاصطناعي والوكلاء:** Claude · Claude Code · ChatGPT · واجهات API متوافقة مع OpenAI · وكلاء قائمون على الأدوار · استدعاء الأدوات · RAG

**الهندسة:** Python · TypeScript / JavaScript · SQL · واجهات REST API · Webhooks · Docker · Git/GitHub · CI · اختبارات آلية · قواعد بيانات · طوابير · مراقبة

**الأتمتة والإعلام:** تكاملات متصفح/API مسموحة · Telegram Bot API · ElevenLabs · خطوط إنتاج AI للنصوص والصور والفيديو والصوت

## مشاريع عامة مختارة

- [**Social Media Crossposter**](https://github.com/GeniusBotsLab/social-crossposter-comment-module) — مساحة عمل لنشر النصوص والصور والفيديو إلى الحسابات والقنوات المصرح بها عبر تكاملات مسموحة.
- [**Swarm Agent Coordinator**](https://github.com/GeniusBotsLab/swarm-agent-coordinator) — تنسيق مستضاف ذاتيًا لفرق الوكلاء والمهام والأدوار وغرف العمل.
- [**TextFix**](https://github.com/GeniusBotsLab/textfix) — أداة Windows لتصحيح النص بمساعدة AI عبر واجهة API متوافقة مع OpenAI.
- [**NeuroMedia Marketplace**](https://github.com/GeniusBotsLab/neuromedia-marketplace) — واجهة عرض عامة متعددة اللغات لـ AI Marketplace ومزامنة آمنة للكتالوج.
- [**Self-Correcting Link Parser**](https://github.com/GeniusBotsLab/self-correcting-link-parser) — جمع الروابط العامة وتطبيعها وضبط جودتها لسير عمل بحثي ملتزم.
