# GeniusBotsLab — أتمتة الذكاء الاصطناعي وتسليم البرمجيات وسير عمل الفيديو

**مطور أتمتة AI · مطور بمساعدة AI · منشئ سير عمل فيديو بالذكاء الاصطناعي**

أبني سير عمل عملياً وخاضعاً للمراجعة البشرية للبرمجيات والأتمتة وإنتاج الفيديو. أستخدم Claude وClaude Code وChatGPT وCursor للبحث والتحليل والمسودات والاختبار والتوثيق، مع مراجعة بشرية للكود والنتائج النهائية.

## المجالات

- أتمتة AI وسير عمل الوكلاء مع مدخلات واضحة ومخرجات منظمة ومراحل تحقق.
- تسليم برمجيات بمساعدة AI: تحليل المستودعات والتنفيذ الأولي وإعادة البناء والاختبارات والتوثيق.
- سير عمل فيديو AI: brief ومفهوم وخيارات للمشاهد واختيار ومونتاج وترجمة نصية وفحص جودة.
- LLMOps / AgentOps: توجيه النماذج والسجلات وإعادة المحاولة والتحكم في التكلفة والموافقة البشرية.

تُعرض فقط الأعمال المستقلة القابلة للنشر؛ لا توجد بيانات عملاء أو بيانات اعتماد أو بنية خاصة.
