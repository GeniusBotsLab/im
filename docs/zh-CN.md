## 工作方向

- **AI 自动化与智能体工作流：** 明确输入、结构化输出和人工审核步骤。
- **AI 辅助软件交付：** 使用 Claude、Claude Code、ChatGPT 和 Cursor 进行代码库分析、任务拆分、初稿实现、重构、测试和文档；最终代码由人工审查和验证。
- **AI 视频工作流：** 从 brief、创意与场景方案，到素材选择、剪辑、字幕和最终质检。
- **LLMOps / AgentOps：** 模型路由、上下文控制、重试/回退、日志、成本控制以及关键操作的人工审批。
