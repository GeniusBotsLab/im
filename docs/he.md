# GeniusBotsLab — מערכות סוכנים ואוטומציית AI אמינה

**מהנדס אוטומציית AI לתהליכים עסקיים מבוקרים ומדידים.**

אני מתכנן מערכות AI שבהן סוכנים מתמחים חוקרים, מתכננים, מבצעים, סוקרים, מאמתים ומדווחים באמצעות העברות משימה מפורשות, הרשאות, תקציבים, יומנים ואישור אנושי לפעולות מהותיות.

## יכולות

- **תזמור רב-סוכני** — תפקידי חוקר, אנליסט, מתכנן, מבצע, סוקר, מאמת ודיווח עם תחומי אחריות מוגדרים.
- **תהליכי עבודה ארוכי טווח** — מצב, תורים, לוחות זמנים, נקודות ביקורת, ניסיונות חוזרים, פסקי זמן, התראות, יומני ביקורת ושערי אישור.
- **מסירת תוכנה בסיוע AI** — Claude, Claude Code ו-ChatGPT מסייעים במחקר, מימוש, סקירה, תכנון בדיקות ותיעוד; האחריות על ארכיטקטורה, אבטחה, אימות, הפצה והחלטות נשארת בידי אנשים.
- **תהליכי רשתות חברתיות ומדיה מורשים** — פרסום מאושר, ניהול תגובות ומענה להן, תכנון תוכן, צינורות תמונה/וידאו/קול, דיווח ותפעול פנימי.

## נוהג הנדסי

```text
ביקורת תהליך → מדדי פיילוט → תפקידים וגישה → בנייה → בדיקות ו-QA → השקה מבוקרת → ניטור עלות, איכות ושגיאות → שיפור
```

בדיקות יחידה, אינטגרציה וקצה-לקצה נדרשות במקרים המתאימים, ו-CI מריץ את הבדיקות האוטומטיות שסוכמו. קלטים ופלטים מובְנים מאומתים; תוצאות עמומות או בעלות השפעה גבוהה עוברות סקירה אנושית.

### מודלים, RAG ואמינות

- מנתב מודלים לפי מורכבות המשימה, דרישות האיכות והעלות.
- שולט בהקשר, שומר במטמון תוצאות שניתנות לשימוש חוזר ומגדיר תקציבי טוקנים ופעולות.
- משתמש ב-RAG ובתהליכים מצביים כאשר אחזור מבוסס מקורות מתאים.
- מפעיל מערכות עם נצפוּת, הרשאות, סטטוס מסירה, נתיבי ניסיון חוזר/גיבוי וטיפול מתועד בכשלים.

## טכנולוגיות

**AI וסוכנים:** Claude · Claude Code · ChatGPT · ממשקי API תואמי OpenAI · סוכנים מבוססי תפקידים · קריאה לכלים · RAG

**הנדסה:** Python · TypeScript / JavaScript · SQL · ממשקי REST API · Webhooks · Docker · Git/GitHub · CI · בדיקות אוטומטיות · מסדי נתונים · תורים · ניטור

**אוטומציה ומדיה:** שילובי דפדפן/API מותרים · Telegram Bot API · ElevenLabs · צינורות AI לטקסט, תמונות, וידאו וקול

## פרויקטים ציבוריים נבחרים

- [**Social Media Crossposter**](https://github.com/GeniusBotsLab/social-crossposter-comment-module) — סביבת עבודה לפרסום טקסט, תמונות ווידאו לחשבונות ולערוצים מורשים באמצעות שילובים מותרים.
- [**Swarm Agent Coordinator**](https://github.com/GeniusBotsLab/swarm-agent-coordinator) — תיאום באירוח עצמי לצוותי סוכנים, משימות, תפקידים וחדרי עבודה.
- [**TextFix**](https://github.com/GeniusBotsLab/textfix) — כלי Windows לתיקון טקסט בסיוע AI באמצעות API תואם OpenAI.
- [**NeuroMedia Marketplace**](https://github.com/GeniusBotsLab/neuromedia-marketplace) — תצוגת AI Marketplace ציבורית רב-לשונית וסנכרון קטלוג בטוח.
- [**Self-Correcting Link Parser**](https://github.com/GeniusBotsLab/self-correcting-link-parser) — איסוף קישורים ציבוריים, נרמול ובקרת איכות לתהליכי מחקר תואמי כללים.
