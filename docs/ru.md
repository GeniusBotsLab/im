**Инженер AI-автоматизации · AI-assisted разработчик · Создатель AI-видеопайплайнов**

Создаю практические AI-assisted решения для автоматизации, разработки и видеопроизводства. В основе — понятные входные данные, контролируемая работа инструментов, проверка качества, ручное подтверждение важных действий и полезный итоговый результат.

## Направления работы

- **AI-автоматизация и агентные workflow:** исследования, документы, API и доставка результатов со структурированными выходами и этапами проверки.
- **AI-assisted разработка:** использую Claude, Claude Code, ChatGPT и Cursor для исследования кодовой базы, декомпозиции, черновых изменений, рефакторинга, тестов и документации; финальный код проверяю и тестирую вручную.
- **AI-видео:** от брифа и сценария до вариантов сцен, отбора, ручного монтажа, субтитров и адаптаций для short-form форматов.
- **LLMOps / AgentOps:** маршрутизация моделей, управление контекстом, retry/fallback, логи, контроль затрат и human-in-the-loop для значимых действий.

## Подход к работе

```text
Бриф → Исследование → Проектирование → Реализация → Проверка → Ручной review → Передача результата
```

Публично показываются только проверяемые самостоятельные материалы. Клиентские данные, ключи, приватная инфраструктура и закрытые материалы не публикуются. Любые числовые результаты и production-утверждения появляются только при наличии разрешённого доказательства или обезличенного кейса.
